# پرسش‌های احتمالی دفاع

1. چرا دستور دوم در RAW فقط Replay می‌شود و کل Pipeline Stall نمی‌شود؟
2. چرا WAR در معماری In-order مسئله نیست؟
3. اگر هر دو Lane در Writeback روی یک ثبات بنویسند چه می‌شود؟
4. چرا در Benchmark Memory پنج Front-end stall ثبت شده است؟
5. چرا در Single mode مقدار Replay زیاد است و آیا Hazard محسوب می‌شود؟
6. چرا Speedup مستقل به 2× نرسیده است؟
7. Redirect priority چگونه تعیین شده است؟
8. تفاوت `memory_conflict_count=0` با نبود محدودیت RAM چیست؟
9. چرا Branch از ALU zero استفاده می‌کند؟
10. برای افزایش کارایی نسخه بعدی چه تغییراتی پیشنهاد می‌شود؟
