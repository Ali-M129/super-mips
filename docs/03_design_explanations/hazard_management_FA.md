# مدیریت مخاطرات

## RAW
اگر slot1 ثبات مقصد slot0 را بخواند، صدور هم‌زمان ممنوع و slot1 Replay می‌شود. وابستگی میان دستورهای چرخه‌های مختلف با Forwarding از E/M و M/W حل می‌شود.

## WAW
اگر هر دو دستور روی یک ثبات مقصد بنویسند، Issue Unit از هم‌زمانی جلوگیری می‌کند. علاوه بر آن، Writeback و Register File یک محافظ دفاعی دارند که در برخورد واقعی تنها نوشتن Lane1 جوان‌تر را معتبر می‌کند.

## Load-use
نتیجه Load در E/M هنوز برای مصرف‌کننده آماده نیست. واحد Load-use کل جفت را یک چرخه نگه می‌دارد، Bubble وارد Backend می‌کند و پس از رسیدن Load به M/W مقدار را Forward می‌کند.

## کنترل
سیاست Always Not Taken استفاده می‌شود. هنگام Branch گرفته‌شده یا Jump، Redirect با اولویت مشخص ساخته و ثبات‌های مسیر اشتباه Flush می‌شوند. JR Resolver مقصد را از RF یا مسیرهای Forwarding استخراج می‌کند و اگر مقدار هنوز آماده نباشد Stall می‌دهد.
