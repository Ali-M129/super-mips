# حافظه مشترک و فایل ثبات

## حافظه
RAM داده تک‌پورتی است. Issue Unit به‌صورت پیشگیرانه اجازه نمی‌دهد دو دستور حافظه در یک جفت وارد Pipeline شوند. Shared Memory Arbiter نیز به‌عنوان محافظ دفاعی درخواست‌ها را سری می‌کند و Lane0 را مقدم می‌داند. در Benchmarkهای رسمی `memory_conflicts=0` است، زیرا تعارض پیش از رسیدن به RAM حذف می‌شود.

## فایل ثبات
برای رمزگشایی دو دستور، چهار پورت خواندن و برای Writeback دو پورت نوشتن وجود دارد. نوشتن در R0 غیرفعال است. Bypass همان‌چرخه از Writeback به Decode پشتیبانی می‌شود. در برخورد دو نوشتن روی مقصد یکسان فقط یک نوشتن معتبر می‌ماند.
